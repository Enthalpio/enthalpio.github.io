Возможности

❄️ Холодильное оборудование (М1–М3)

Теплопритоки (Q1–Q6), холодопроизводительность (COP по Карно), фреонопровод (нагнетание, всас, жидкость), диаметры по ASTM, ΔP, маслопетли. КИПиА: ТРВ, соленоиды, ресиверы, отделители.

💨 Вентиляция (М4)

Расход воздуха, мощности, воздуховоды, подбор вентилятора. Кухни и рестораны (СП 60.13330.2020). DX-приточка: подбор ККБ. Местные отсосы.

🌡️ Кондиционирование (М5)

Нагрузки (лето/зима), подбор по BTU, ток, кабель, автомат, трубопроводы, дренаж.

🖥️ Серверные / ЦОД (М6)

Теплопритоки от IT-оборудования, подбор CRAC с учётом класса Tier (I–IV), холодный / горячий коридор.

💧 Чиллеры (М7)

Comfort / Process, прецизионные пресеты T_воды, EER, гидравлика контура, насосы, расширительный бак.

🔥 Отопление (М8)

Теплопотери через ограждения, инфильтрация, подбор радиаторов (метод Тихомирова), гидравлика, элеватор, насос.

🌊 Градирни (М9)

Тепловой и аэродинамический расчёт, подбор вентиляторов, потери на испарение, ХВО, гидравлика оборотной воды.

📄 Сквозной PDF с брендингом

Один объект — один PDF. Сплошная техническая документация. Возможность вставить логотип и реквизиты вашей компании для отправки клиентам.

💾 Сохранение проектов

База проектов с заказчиками и объектами. Продолжите расчёт в любой момент. Сводные результаты по всем модулям.
