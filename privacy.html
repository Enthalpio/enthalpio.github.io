1. Общие положения

Настоящая Политика конфиденциальности (далее — Политика) определяет порядок обработки и защиты информации о пользователях мобильного приложения Enthalpio (далее — Приложение).

Оператором персональных данных является ИП Петров Павел Игоревич (ОГРНИП: 320602700017796, г. Ногинск, Московская область).

2. Какие данные собираются

Приложение не собирает, не хранит и не передаёт персональные данные пользователей.

Все расчёты выполняются локально на устройстве пользователя. Данные расчётов, сохранённые проекты и экспортированные PDF-файлы хранятся только на устройстве пользователя и не передаются на серверы Оператора.

Приложение не запрашивает доступ к:

  • геолокации;
  • контактам;
  • камере;
  • микрофону;
  • личным файлам, кроме случаев сохранения PDF по выбору пользователя.

3. Обработка данных

Оператор не обрабатывает персональные данные пользователей Приложения.

Техническая информация (модель устройства, версия операционной системы) может собираться автоматически магазином приложений RuStore в соответствии с его собственной политикой конфиденциальности.

4. Передача данных третьим лицам

Оператор не передаёт какие-либо данные пользователей третьим лицам, поскольку такие данные не собираются.

5. Права пользователя

Пользователь имеет право использовать Приложение без предоставления персональных данных и удалить Приложение в любой момент, что приведёт к удалению всех локальных данных.

6. Изменения в Политике

Оператор вправе изменять настоящую Политику. Актуальная версия всегда доступна по адресу: https://enthalpio.github.io/privacy.html.
